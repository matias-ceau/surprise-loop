# Two Maps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a hidden grid world that a creature learns only through what its body feels, the creature's own map and a careful reasoner's map kept side by side, runs on stand-ins and on a model, two gates, and a film of three maps.

**Architecture:** a plain async loop calls seven phase functions over one frozen `Workspace`: Perceive, Deliberate, Act, Monitor, Evaluate, Appraise, Reconcile. `GridWorld` owns the layout and each body's true numbers. On the creature's side, `lens.py` turns true numbers into a worded felt record through the temperament, `reasoner.py` keeps the careful reasoner's map, and the creature's own map is changed only by Appraise's answer. Deliberate and Appraise each have a model backend and deterministic stand-ins chosen in the config.

**Tech Stack:** Python >= 3.12, uv, pydantic v2, pydantic-ai 2.x, pyyaml, pytest, ruff. The film is self-contained HTML written by the standard library.

**Spec:** `docs/superpowers/specs/2026-11-21-two-maps-design.md`. It is the authority. The colour reference is `docs/superpowers/specs/2026-11-21-two-maps-colours.html`.

## Global Constraints

- No new dependency. No web framework, no JavaScript library.
- Every model is pydantic v2 on `Frozen` (`extra="forbid"`, `allow_inf_nan=False`, `frozen=True`).
- Every number that shapes behaviour lives in `config.py` defaults, the experiment YAML, or a `Temperament`. Phase code holds no numeric literal other than structural 0, 1 and clamps to documented ranges.
- The model's name comes from the config `model` or the env var `SURPRISE_LOOP_MODEL`. Never hard-coded.
- All randomness goes through `derive_rng(seed, *key)`. No `hash()`, no global `random`, no clock, no timestamps in tick files.
- The world never names a tile to the creature. `Kind`, `StepInfo` and true body numbers never reach a prompt or a stand-in chooser.
- No text a model reads contains the words game, simulation or experiment, a true body number, or a temperament's gain, noise or blur. The presumption reaches the model only as the beliefs its map starts with. Feelings are words.
- A phase is `async def phase(ws: Workspace, rt: Runtime) -> Workspace` and returns a copy. The input is never mutated.
- Evaluate changes only the reasoner's state carried on the workspace. Nothing of the reasoner's is ever placed in a prompt.
- A failed model call stops the run. There is no fallback to a stand-in.
- Tests make no network call (`tests/conftest.py` sets `models.ALLOW_MODEL_REQUESTS = False`).
- `uv run ruff check . && uv run ruff format --check . && uv run pytest` is green before every commit.
- The previous build is at commit `24aff96`. Where a task says "restore", read the old file with `git show 24aff96:<path>` and adapt it; do not check the old tree out.

## Review Focus

1. **A layout edited by hand**: ragged rows, no `@` or two, an unknown character, a start with no tile to step onto. Expected: one config error line naming the row and column. Tests in Task 2 and Task 3.
2. **A temperament that presumes a kind has zero share, and the world contains it.** Expected: the reasoner never divides by zero and falls back to equal shares over the kinds the evidence allows. Shares that do not sum to one are a config error. Tests in Task 3 and Task 5.
3. **A model that writes a change for a far-off spot, repeats a spot, or sends too many changes.** Expected: retried, then a loud stop; nothing out of range is ever applied. Tests in Task 10.
4. **An interrupted run.** Expected: a resumed stand-in run is byte-identical to an uninterrupted one; a replay of a model run makes no model call. Tests in Task 7 and Task 10.
5. **Two runs handed to `film` that do not belong together**: different layout, different length, an unfinished run, the same directory twice. Expected: one error line and no page. Tests in Task 11.

## Decisions this plan makes beyond the spec

1. **Clean slate first.** Task 1 deletes the clearing's modules, tests and experiment files, so every later task ends green. Reusable code is restored from `24aff96` by the task that needs it.
2. **Gain and noise apply to the six body channels.** Smell and damp are counts and reach every creature unchanged.
3. **Memory keeps only the last `memory.recent_k` episodes.** Only those are ever read back, and a tick file that repeats every episode grows with the square of the run.
4. **The rule chooser explores for its own sake only when its map presumes more good than harm of an untried tile** (`feeds + quenches + pleases > hurts`). Otherwise it explores only when a need is loud and no known tile serves it, or when it knows nothing safe yet. It heads for a tile it believes harmful only when a need is loud and nothing safer is left to try, or when the need is desperate and that tile is believed to serve it.
5. **The distance between two maps is taken over the layout tiles both runs have tried.** That isolates what two creatures concluded about the same places.
6. **Every creature starts with hunger 0.2 and thirst 0.2**, so no need is loud at the first step.
7. **`ticks` stays as an optional cap on a run**, for tests and for gate 2. The length of a day is `world.steps`.
8. **The model is shown the size of its last surprises as a word** (none, small, large) and whether the step went better or worse than expected.
9. **A change for a spot outside `rule.reach` of the start, or more than `appraise.max_changes` changes, is sent back to the model.** Within one answer a later change to the same spot wins.
10. **The film embeds the starting maps and each tick's changes**, and the page rebuilds every frame when it loads.
11. **Task 1 is done by the controller**, since it is deletion and the brief.
12. **Smell and damp can miss.** Each neighbouring thing is noticed with a chance from the config. The default of 1.0 is the spec's exact count; the experiment files use 0.7. With an exact count, a blocked step with no damp is certainly not water, and the owner's own example of doubt ("a wall, or water I did not need") could never arise.

Layout rules, checked in a `field_validator("layout")` so that a config error names `world.layout`, each a `ValueError` naming row and column (both counted from 1): at least one row; rows of equal length; only characters of `LAYOUT_CHARS`; exactly one `@`; at least one of the start's four neighbours is inside the layout and walkable.

A tile at column `c`, row `r` (both from 0, row 0 the northernmost) with the start at `(c0, r0)` has position `(c - c0, r0 - r)`.

One step, in this order:

1. `WorldDone` if `step == config.steps`. Otherwise `step += 1`; `target = moved_to(position, direction)`; `kind = kind_at(config, target)`.
2. Drift: `hunger += hunger_rate`, `thirst += thirst_rate`, and `ache`, `sickness`, `unease`, `pleasure` are each multiplied by one minus their fade.
3. The target:
   - walkable: `position = target`, `moved = True`. PLEASANT adds `pleasure_dose` to pleasure, UNPLEASANT adds `unease_dose` to unease.
   - OBSTACLE: `moved = False`, nothing else.
   - FOOD, TOXIC: `moved = False`; `excess = max(0, food_portion - hunger)`; `hunger = max(0, hunger - food_portion)`; `ache += ache_per_excess * excess`.
   - WATER, FOUL: `moved = False`; `thirst = max(0, thirst - water_portion)`.
   - TOXIC, FOUL also append `step + derive_rng(seed, "sick", step).choice(sick_delays)` to `pending_sickness`.
4. Every pending sickness whose step is `<= step` adds `sick_dose` to sickness and is removed; `sickness_arrived` is true if any did.
5. Every channel is clamped to 0..1.
6. `smell` is the number of the new position's four neighbours whose kind is FOOD or TOXIC and that are noticed; `damp` likewise for WATER or FOUL. Each such neighbour is noticed when `rng.random() < smell_chance` (or `damp_chance`), with `rng = derive_rng(seed, "nose", step)` drawn once per neighbour in the order north, east, south, west, for smell first and then damp, whatever the neighbour's kind. `observe()` uses step 0.

`done` is `step >= config.steps`.

### `lens.py` and `feeling.py`

```python
# lens.py
BLUR_GROUPS: tuple[tuple[Channel, ...], ...]   # (HUNGER, THIRST), (ACHE, SICKNESS, UNEASE)
def felt_levels(body: dict[Channel, float], t: Temperament, rng: random.Random) -> dict[Channel, float]
def ladder_step(level: float, edges: tuple[float, ...]) -> int     # the number of edges <= level
def near_step(count: int) -> int                                    # min(count, 2)
def sense(signal: Signal, t: Temperament, rng: random.Random, p: LensParams) -> tuple[dict[Channel, int], int, int]   # levels, smell, damp

# feeling.py
def tone_step(levels: dict[Channel, int], p: FeelingParams) -> int
def next_stir(stir: float, surprise: float, p: FeelingParams) -> float
def stir_step(stir: float, p: FeelingParams) -> int
```

`felt_levels`, in this order: for each group of `BLUR_GROUPS`, `x = (1 - blur) * x + blur * mean(group)`; then `x *= gain`; then `x += rng.gauss(0, noise)`, one draw per channel in `Channel` order; then clamp to 0..1.

Tone: `value = clamp(sum(sign * tone_weights[c] * levels[c]) / 4, -1, 1)` with sign +1 for pleasure and -1 for the others; `tone_step` is the number of `tone_edges <= value`.

Stir: `next_stir = (1 - stir_rate) * stir + stir_rate * surprise`; `stir_step` is the number of `stir_edges <= stir`.

Seeds: the senses use `derive_rng(config.seed, "sense", tick)`, with tick 0 for the starting record.

### `phases/monitor.py`: the comparison

```python
def compare(e: Expectation, moved: bool, levels: dict[Channel, int], smell: int, damp: int, p: MonitorParams) -> Comparison
```

- `misses[c] = levels[c] - e.levels[c]`; `smell_miss`, `damp_miss` likewise; `moved_miss = moved != e.moved`.
- `raw = moved_weight * moved_miss + sum(channel_weight[c] * abs(misses[c]) / 4) + sense_weight * (abs(smell_miss) + abs(damp_miss)) / 2`
- `surprise = min(1, sure_factor[e.sure] * raw / scale)`
- `worse = sum(sign * misses[c]) / 4`, sign -1 for pleasure and +1 for the others.

### `reasoner.py`

```python
def initial_reasoner(presumes: dict[Kind, float]) -> ReasonerState
def shares_at(state: ReasonerState, at: Position) -> dict[Kind, float]
def marginals(shares: dict[Kind, float]) -> dict[Belief, float]      # for each belief, the sum of the shares of the kinds that have it in EFFECTS, at most 1.0
def reasoner_beliefs(state: ReasonerState, at: Position) -> dict[Belief, float]
def reason(state: ReasonerState, step: int, direction: Direction, before: FeltRecord, after: FeltRecord,
           body: BodyParams, p: ReasonerParams) -> tuple[ReasonerState, tuple[Position, ...]]
```

`reason` returns the new state and the positions whose `reasoner_beliefs` moved by more than 1e-9, sorted. With `s = p.slip`, `target = moved_to(before.at, direction)` and `window = max(body.sick_delays)`, it does this, in order:

1. **Moved.** If `after.moved`, set the target's shares of the five kinds outside `WALKABLE` to 0; otherwise set the three walkable kinds to 0. Renormalise. If nothing is left, give equal shares to the kinds of the group that was kept.
2. **What changed at once.** Events, from the ladder steps before and after: `fed` hunger fell, `quenched` thirst fell, `ached` ache rose, `pleased` pleasure rose, `uneased` unease rose. Multiply the target's share of each kind by the likelihood of every relevant event's observed value, then renormalise.
   - After a blocked step the relevant events are `fed`, `quenched`, `ached`:
     - P(fed) is `1 - s` for FOOD and TOXIC when `before.levels[HUNGER] >= 1`, else `s`.
     - P(quenched) is `1 - s` for WATER and FOUL when `before.levels[THIRST] >= 1`, else `s`.
     - P(ached) for FOOD and TOXIC is `1 - s` when `before.levels[HUNGER] == 0`, `p.ache_when_slight` when it is 1, else `s`; for other kinds `s`.
   - After a step that moved, the relevant events are `pleased` and `uneased`: P(pleased) is `1 - s` for PLEASANT, else `s`; P(uneased) is `1 - s` for UNPLEASANT, else `s`.
3. **Touches.** After a blocked step append `Touch(step, target)`. Drop touches and onsets older than `step - window`.
4. **Sickness arrived** (`after.levels[SICKNESS] > before.levels[SICKNESS]`): record the onset. The candidates are the touches with `step - touch.step` in `body.sick_delays`. With `h(tile)` the tile's share of TOXIC plus FOUL, each candidate weighs `h(tile) / len(sick_delays)`. If the weights sum to 0, change nothing. Otherwise `r(tile)` is the tile's summed weight over the total, and its harmful share becomes `r + (1 - r) * h`: TOXIC and FOUL are scaled together to that total and the other kinds to the rest.
5. **Cleared.** For every touch with `step - touch.step == window` that no recorded onset `o` follows with `o - touch.step` in `body.sick_delays`: multiply that tile's TOXIC and FOUL shares by `s` and renormalise.
6. **Smell, then damp**, at `after.at`. For smell the group is FOOD and TOXIC, the observation is `after.smell` and `q = body.smell_chance`; for damp it is WATER and FOUL, `after.damp` and `q = body.damp_chance`. With `e_i` the group's share at neighbour `i`, enumerate the 16 ways the four neighbours can each hold the group or not. Weigh each by the product of `e_i` or `1 - e_i`, times the chance of the observation given that `k` neighbours hold the group: `(1 - q) ** k` for 0, `k * q * (1 - q) ** (k - 1)` for 1, and one minus those two for 2. If the weights sum to 0, change nothing. Otherwise each neighbour's new group share is the weight in which it holds the group over the total; scale the group's kinds to that and the other kinds to the rest.

**`rule_choice`.** Write `b(t)` for `own_map.at(t)`.

- `safe(t)`: `b(t)[HURTS] < p.avoid_at`. `passable(t)`: `b(t)[BLOCKS] < p.believe_at and safe(t)`. `tried(t)`: `tries.get(key(t), 0) >= 1`.
- The need is HUNGER or THIRST, whichever has the larger felt step, HUNGER on a tie, if that step is `>= p.need_at`; otherwise there is none.
- A tile serves the need when its `FEEDS` (for hunger) or `QUENCHES` (for thirst) is `>= p.serve_at`, whether or not it has been tried. The need is desperate when its felt step is `>= p.desperate_at`.
- Goal sets, tried in this order until a search finds one:
  - with a need that is not desperate: (1) serving, safe tiles; (2) untried, safe tiles; (3) serving tiles, safe or not; (4) untried tiles, safe or not;
  - with a desperate need: (1) serving, safe tiles; (2) serving tiles, safe or not; (3) untried, safe tiles; (4) untried tiles, safe or not;
  - with no need and `untried[FEEDS] + untried[QUENCHES] + untried[PLEASES] > untried[HURTS]`: (1) untried, safe tiles; (2) tried, safe tiles;
  - with no need otherwise: (1) tried, safe tiles; (2) untried, safe tiles.
- A search is breadth-first from `felt.at`, visiting neighbours in the order north, east, south, west, over tiles within `p.reach` of `(0, 0)` in both coordinates. The tile the creature stands on is never a goal. A goal tile ends a path whether or not it is passable; only passable tiles are walked through. It collects the first direction of every shortest path to a goal.
- If no search finds a goal, `best` is every direction whose target is safe, or all four if none is.
- `best` is in `Direction` order without repeats; `choice = rng.choice(best)`.

**`rule_expectation`.** With `target = moved_to(felt.at, direction)` and `b = own_map.at(target)`:

- `moved = b[BLOCKS] < p.believe_at`; `levels` starts as `felt.levels`.
- Not moved and `b[FEEDS] >= p.believe_at`: hunger one step lower if it is at least 1, else ache one step higher (at most 4).
- Not moved and `b[QUENCHES] >= p.believe_at` and thirst at least 1: thirst one step lower.
- Moved and `b[PLEASES] >= p.believe_at`: pleasure at least `p.felt_step`. Moved and `b[HURTS] >= p.believe_at`: unease at least `p.felt_step`.
- `smell` is `near_step` of the number of neighbours `n` of where it expects to stand with `own_map.at(n)[FEEDS] >= p.believe_at`; `damp` likewise with `QUENCHES`.
- `sure`: SURE with at least `p.sure_tries` tries of the target, FAIRLY_SURE with at least `p.fairly_sure_tries`, else GUESSING.

**`blind_decision`.** `direction = rng.choice(list(Direction))`; the expectation is `moved=True`, the levels, smell and damp of `felt`, `sure=GUESSING`; `why=""`.

**`measures`.** Tried tiles are the positions in `agent.tries` with a count of at least 1. For a set of tiles, the error of a map is the mean of `abs(belief - truth)` over the tiles and the five beliefs, and 0.0 for an empty set; the gap is the same between the creature's own map and `reasoner_beliefs`. `start_error` is the error of `own_map.untried` over the tried tiles. False harm is a tried tile with `HURTS >= p.wrong_side` where the truth is 0; false safety is the reverse. `wrong` lists the tried tiles where any of the creature's five beliefs is on the wrong side of `p.wrong_side`.

**The seven phases.**

| Phase | What it does |
|---|---|
| `perceive` | `Percept(recent=tuple(agent.memory.episodes), rule=rule_choice(agent.felt, agent.own_map, agent.tries, params.rule, derive_rng(seed, "rule", tick)))`. |
| `deliberate` | `rule`: `Decision(percept.rule.choice, rule_expectation(...), why="")`. `blind`: `blind_decision(agent.felt, derive_rng(seed, "blind", tick))`. `llm`: Task 10. |
| `act` | `outcome = rt.world.step(decision.direction)`. The only phase that touches the world. |
| `monitor` | `sense(outcome.signal, temperament, derive_rng(seed, "sense", tick), params.lens)`; `compare(...)`; `stir = next_stir(agent.stir, comparison.surprise, ...)`; `felt_after = FeltRecord(moved, levels, smell, damp, tone_step(levels), stir_step(stir), at=signal.position)`. |
| `evaluate` | `reason(agent.reasoner, tick, decision.direction, agent.felt, felt_after, config.world.body, params.reasoner)` into `ws.reasoner` and `ws.reasoner_changed`. |
| `appraise` | `reasoner`: `Appraisal(reading="", changes=` one `Change` per position of `ws.reasoner_changed` with `reasoner_beliefs(ws.reasoner, position)` `)`. `llm`: Task 10. |
| `reconcile` | New agent: `own_map.changed(appraisal.changes)`; one more try for the target, `moved_to(agent.felt.at, decision.direction)`; `felt = felt_after`; `stir`; `reasoner = ws.reasoner`; memory with the new `Episode` (salience = surprise) cut to the last `recent_k`. Then `measures(...)` on the new agent, and `ws.record`. |

Here `tick` is the tick in progress, `agent.tick + 1`. `loop.tick` advances `agent.tick` after `reconcile`.

`initial_agent_state(config, signal)`: the felt record from `sense(signal, temperament, derive_rng(seed, "sense", 0), params.lens)` with `moved=None`, tone from its levels, stir step 0, `at=(0, 0)`; `stir=0.0`; `own_map=CreatureMap(untried=marginals(presumes), tiles={})`; `reasoner=initial_reasoner(presumes)`; no tries, empty memory, `tick=0`.
